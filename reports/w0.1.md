The contract tests include true synthetic multi-asset/sidecar roundtrips, strict
read/write loss, decoder errors, resource limits, safe path validation, output
collisions, content-vs-extension precedence, ambiguous detection, invalid and
repeated registration, and report serialization. CLI tests execute the binary and
verify failure never creates or overwrites output. The fixture byte protocol is
not a real font format and is never registered in production.

Earlier nonfinal diagnostics: cargo-deny initially warned about approved-but-unused
license entries; the final allowlist contains only encountered approved licenses.
An extra documentation check exposed Cargo's binary/library output path collision;
`doc = false` on the CLI binary resolved it. Neither diagnostic was ignored.

From repository root, `source ../../toolchain/activate.sh` sets isolated
`CARGO_HOME`, `RUSTUP_HOME`, and `PATH` for the current shell. Full local logs are
in the adjacent toolchain directory (`w0.1-check-final.log`, `w0.1-doc-final.log`,
`w0.1-formats.txt`). They are not required to build a cloned repository.

## Not run / not implemented

- W0.2 charset generation and all phase-1+ model, bitmap, codec, render, and
  compatibility work: not started by this item
- No built-in content detector, font reader, writer, gzip decoder, font performance
  benchmark, parity suite, font roundtrip, external crosscheck, or reader fuzz run
- Reserved binding crates have no binding API and zero tests; their successful
  compilation is not Python/WASM functional validation
- Remote CI is configured but has not been run; no remote repository was created
- No filesystem resolver or multi-file persistence layer yet. Future adapters must
  enforce symlink-safe roots and platform path restrictions; strict conversion is
  enforced at the in-memory bundle boundary, not a claim of atomic filesystem I/O
- Format-specific strong option types and the actual `FontSet` arrive with their
  assigned implementations; generic registry contracts are their integration seam
