## Implemented

- Exhaustive expanded-outline grid detection, native ppem 4–64, explicit ppem,
  grid-unit and origin overrides. Deterministic center-sampling handles line,
  quadratic and cubic paths with nonzero winding and no flattening tolerance.
- Matching embedded-strike preference, sparse outline fallback, ordered complete
  glyph retention, aliases/unencoded glyphs, names and horizontal/vertical metrics.
  TrueType phantom origins / USE_MY_METRICS and CFF VORG are accounted for.
- Native TTF/OTF/WOFF/WOFF2/TTC and vector-raster registry/API support, configurable
  codecs and CLI raster/vector options. Native writing preserves single-face
  physical glyph identity, .notdef, aliases and unencoded glyphs.
- TTC/OTC v1/v2 read/all-or-selected face extraction and deterministic same-tag
  table sharing. Mixed outline flavors, bounded shared spans, malformed offsets,
  signature removal diagnostics and aggregate expansion limits are supported.
- WOFF2 collection directories, ordered faces, sharing, complete glyf/loca
  transforms, CFF, malformed-pair rejection and standalone extraction. Optional
  hmtx transforms remain null for collections to avoid context-dependent sharing.

## Final hardening

The generated TrueType dot-helper name is reserved before source name allocation.
Collection diagnostics use flattened FontSet indices. Native wrappers preserve
EBSC instructions for selected strikes, qualify them by source face in a TTC,
and explicitly report discarded raw-table provenance. All have focused regressions;
metadata retention remains charged to the aggregate model-byte budgets.

## Explicit boundaries

- Variable instances, CFF2 and previously documented unsupported CFF1 programs
  error. Hint execution, antialiasing and dropout control are not implemented.
- Sparse anisotropic strikes require explicit square ppem or bitmap-only
  extraction; full physical anisotropic strikes are retained.
- Native raster projection preserves a preferred nominal Unicode mapping and
  normalized names, not arbitrary source layout/localized/encoding semantics.
  Conversion losses are reported; low-level table APIs remain the preservation
  path. Each Font in a native TTC write becomes a separate face.
- Installed OTS rejects the mixed TTF/CFF/TTF sequence with the same maxp error
  for our collection and an independently fontTools-written equivalent. Every
  extracted face passes OTS; Google's decoder reconstructs all faces correctly.
- System FreeType 2.13.3 rejects non-first CFF faces directly from WOFF2, including
  an independently Google-compressed equivalent. Every reconstructed raw TTC
  face works. These tool limitations are retained, not presented as passing
  direct-container checks.
- Native timings in the correctness run are not isolated five-run benchmarks.
  W2.8 and the whole-phase export/performance completion gates remain outstanding.
