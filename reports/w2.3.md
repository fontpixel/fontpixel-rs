## 1. 实现范围

- 新增 `sfnt::cff`，由 `cff` feature 启用，`otf` 依赖 `cff`。没有新增运行时
  依赖；复用已锁定的 read-fonts 0.44.0、W2.1 sfnt 与 W2.2 位图轮廓。
- 原生 CFF1 writer：稳定的 Header、Name/Top DICT/String/Global Subrs/
  CharStrings INDEX、format 0 charset、显式 Private DICT 宽度、FontMatrix、
  几何 FontBBox、maxp 0.5。字体名称、SID、数值和偏移都检查后编码。
- 合并方点、独立方点直接使用 W2.2 轮廓；圆点复用像素坐标，使用 Tong 的
  四段三次 Bézier 圆与唯一全局子程序，每个墨点一条 `callgsubr`。
  没有将 TrueType 的四段二次曲线冒充 CFF 三次曲线。
- writer 接受绝对 move/line/cubic/close 轮廓；生成相对 Type 2 指令。
  小整数、shortint 与 16.16 分数分开编码，DICT 使用自身的整数/BCD 编码。
  曲线 bounds 按极值计算，不是控制点矩形；分数经过明示的 16.16 量化。
- reader：借用原始表，支持 name-keyed 与 CID-keyed CFF1、charset 0/1/2 与
  预定义 charset、FDSelect 0/3、多 FD、局部/全局子程序、h/v/relative 曲线、
  flex、hint/counter mask、显式与默认宽度、Top/FD FontMatrix。
- Fontations 前先独立验证完整 INDEX 单调偏移、DICT 参数、SID、charset、
  Private/FD 子结构、字形计数。Type 2 预检验证 48 参数栈、96 hints、10 层
  调用、各指令参数数量、掩码长度、结束指令和坐标累计，拒绝静默恢复。
- Fontations 负责实际轮廓求值，保留三次曲线与分数设计坐标。Private DICT
  分数宽度单独保存，避免 FreeType 风格整数字宽截断。原始表字节仍可读取。
- 预算涵盖输入/表/字形/DICT、每字形及全字体指令工作量和几何命令量；重复
  子程序与空子程序调用同样消耗预算。支持逐字形流式读取和累计受限 read_all。

先写 `docs/formats/cff.md`（并建立 `otf.md` 边界说明），再实现代码。文档记录
官方规格的具体章节、参考源码 SHA-256、字段映射、歧义、量化与信息丢失。
许可证来源为任务包 PLAN §2 明示的同作者 MIT Tong 导出器、现有 MIT/Apache
Fontations；已更新 `THIRD_PARTY_NOTICES.md`，没有复制 GPL 实现。

另保留此前两轮 611 秒 / 33,539,715 与 28,029,162 次运行日志，
不拿它们替代最终验证。
覆盖数字是 libFuzzer 计数，不是源码覆盖率百分比。

## 5. 明示限制与交接事项

- `sfnt::cff` 是原生表/几何 API。OTF 的 FontSet registry hooks 仍未注册；
  `otf`/`cff` feature 被选中不等于完整 FontSet codec 已实现。
- reader 不执行 hints 或 PostScript；不支持 CFF2、Type 1、synthetic fonts、
  seac、除 div 以外的旧 arithmetic/transient-stack 运算、子程序中的 endchar。
  这些情况明确报错，因为锁定的 Fontations evaluator 会忽略或无法完整传播
  部分语义。不能宣称任意 CFF1 字体都能解码。
- writer 是 name-keyed、无 hints 的规范化输出；不保留原始 SID/CID 组织、
  私有调参、任意 DICT 字段、原始 subr 布局和编码。显式路径重编码会展开 subrs。
- 数值采用 Type 2 signed 16.16 边界：advance ≥32768、不可表示的相对位移、
  非有限数、超出 head int16 的 bounds 都报错。不是偷偷将 u16/int32 截断。
- 输出 FullName 要求 printable ASCII；自定义 SID 最高 64999，当前布局最多
  64,609 个命名字形，超限明确失败。完整 SC 的 38,654 字形在范围内。
- 本项没有 native Unicode/bitmap 投影，没有开始 W2.4、merge main、push、
  部署或改写原始 `fontpixel-rs` 快照。690 个 reference/samples 受保护文件的
  SHA-256 全部匹配，无新增文件。没有发生具体动作或目标的权限拒绝。
