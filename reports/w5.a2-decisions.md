# W5.A2 integration decisions for the root agent

All eight registry IDs use their own feature: bbc, comfont, consoleet, grasp,
hrcg, wyse, xbin, zapfont. No Rust dependency was added. Shared registry, CLI,
Cargo, NOTICE and decision files remain root-owned.

1. Keep HRCG out of automatic registry detection: 768-byte length alone provides
   weak evidence. The explicitly selected codec and public detector remain.
2. Native cell options preserve legacy numeric labels by default. Unicode numeric
   projection and Gray8 thresholding are explicit choices. Baseline/charset are
   read interpretations; they do not change the native file's encoding semantics.
3. Wyse preserves the stored 8×16 matrix; repeat-display columns are a terminal
   rendering behavior. The original guide allows positions 00–7F in banks 0–3.
4. Consoleet is a real bounded directory input/output. It requires a list plus
   one read per glyph, checks filenames by numeric value, and never depends on a
   synthetic manifest. The input text length bounds bitmap allocation even with
   caller limits set to usize::MAX.
5. COM input is data only. All output loader bodies are original instructions,
   with only minimal historical identification data. CP/M target selection is
   explicit. PSFCOM 16-row installation and Spectrum's narrow second font report
   runtime projection Loss, in addition to normal file-model audit. DOS PSFCOM
   exits unsupported with status 1. Native hardware and complete OS emulation are
   outside the independent CPU/BIOS-contract verification claim.
6. ZapRedraw honors one-based native ordinal tables, aliases, null offsets and
   unreferenced stored glyphs. Chunk zero is Acorn legacy positions; other chunks
   are Unicode scalars. Unknown unassigned section bytes produce read Loss.
7. XBIN preserves validated palette, flags and raw/RLE screen bytes by default.
   Explicit FontOnly drops them with Loss. Four screen compression modes are
   validated without decompression. Unsupported extra trailers are rejected.
8. No GPL/MPL implementation or loader template was copied. Fixed monobit 0.54.0
   was consulted as an independent MIT oracle and native layout reference;
   CPU engines Unicorn 2.1.4 and kosarev/z80 1.2.0 are external test tools only.
   Their licenses and source hashes are recorded in reports/w5.a2-oracles.md and
   reports/w5.a2-crosscheck.json. No new vendored source needs a library license
   entry; an external-oracle acknowledgement may be added to the shared NOTICE.

Remaining root gates after the handoff are the assigned >=610-second ASan runs,
quiet five-run release measurements, whole-repository tests, and final source
hash verification. This worker does not mark those root gates complete.
