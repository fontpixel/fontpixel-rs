## Implemented

`Variants` owns a default Font plus language and script alternatives. It accepts
OpenType tags and registry-backed BCP-47 language names, configurable language
script lists, Tong's CJK defaults, and script-default western punctuation.
Alternative-only characters become defaults. Alternate bitmaps and **complete**
glyph metrics determine identity; names, encoding and source properties do not.
TC/HK aliases share glyphs. Deterministic glyph order matches Tong's planner.

Native GSUB is constructed directly, without FEA or a runtime Python dependency.
It supports single substitutions, language/feature routing, Coverage 1/2 and
SingleSubst 1/2 reading, type-7 extension wrappers, 64-KiB-safe splitting,
transitive closure, compact remapping, pruning and cumulative traversal limits.

The real `fontpixel variants` command exports square, separate-square and shared
round-dot TrueType/CFF fonts, matching common metadata, optional embedded strikes,
and supported vertical metrics. It exposes naming/scale/gray-threshold options,
language/script configuration, WOFF2 quality/threads and CFF/TTF/auto selection.
The default CLI enables these working commands; minimal core BDF/PCF builds gain
no heavy dependency. General TTF/OTF FontSet/registry readers remain W2.7 work.

The real `fontpixel subset` accepts sfnt/WOFF/WOFF2 and text, UTF-8 text files or
Unicode ranges. It closes over active single substitutions and composites, then
compacts glyph IDs consistently across cmap, horizontal/vertical metrics, post,
GSUB, supported bitmap strikes, VORG, LTSH and hdmx. It preserves exact name bytes
and safe global tables. WOFF auxiliary data survives web-to-web subsets.

TrueType subsetting validates existing glyph data and copies retained raw records,
patching composite child IDs only. Original instructions, bboxes, point encoding
and component flags survive. CFF subsetting relocates CharStrings, charset,
FDSelect/FDArray and private dictionaries while retaining raw Type 2 programs,
hints, widths, matrices, SIDs/CIDs and subroutines. Sparse strike removal also
prunes scaling records with no remaining source strike. Unsupported glyph-indexed
tables fail unless an exact explicit drop was requested. Drops/signature removal
are reported, and strict output fails before replacing a destination.

## Performance and deliberate size tradeoff

Five-run native CLI medians, after correctness/fuzz work, are recorded with all
samples, output sizes, hashes and environment in `benches/results/variants.json`.
Each generation parses all five Large regional/script inputs (including the
TC/HK alias) and writes one output; these are not isolated outline timings:

| Operation | TTF square | CFF square | TTF dot | CFF dot |
|---|---:|---:|---:|---:|
| Regional generation | 4.015 s | 3.174 s | 1.589 s | 1.741 s |
| Small text subset | 0.170 s | 0.033 s | 0.161 s | 0.029 s |

All five outputs per group are byte-identical. The eight retained benchmark
outputs also pass independent fontTools inspection and OTS.

CFF subsets intentionally retain unused strings/subroutines and Font DICTs to
avoid changing SIDs, subroutine bias/computed calls or private semantics. The
measured text subsets are 484,488/486,276 bytes for CFF, versus 5,988/10,228 bytes
for TrueType. This is a real size limitation, not hidden by timing measurements.
Further dead-data pruning is an optimization opportunity. The complete phase-2
84-file export and ≤40-second target are **not** established by these timings.

## Boundaries and coordinator attention

- General GSUB contextual/ligature/alternate behavior, filtering flags, GPOS/GDEF,
  variable/color/other unknown glyph-indexed tables are not silently copied after
  remapping. Unsupported cases fail; exact table drops require explicit options
  and produce loss diagnostics. W2.6 implements its specified single `locl` scope.
- UVS/non-Unicode cmap records and explicit nondefault legacy CFF Encoding are
  refused. CFF2, legacy arithmetic/seac and other unsupported outline-reader
  cases retain the existing W2.2/W2.3 explicit boundaries.
- Unsupported diagonal advances or non-centered vertical origins fail explicitly.
  Glyph zero uses the documented Tong-style generated missing-glyph frame.
- Subsetting preserves sfnt outline flavor. It is not TTF↔CFF conversion. WOFF
  containers can wrap either supported flavor; TTC/OTC and general raster FontSet
  integration remain W2.7.
- All supplied Large regional BDFs and all supplied Latin BDFs were verified.
  Missing full Small/monospaced regional source sets and the complete export
  integration/performance gates are not invented or claimed as tested.

New decisions document explicit table safety, raw-outline fidelity, optional CID
Top DICT Private relocation, conforming DFLT defaults and precise empty-layout
metadata. OTS failures found during review were fixed, not waived. Only inspected
Cargo incremental cache was removed for space; history, inputs and evidence remain.

Requested worker configuration: gpt-6-astra, xhigh, fast. Actual runtime model,
reasoning effort and fast routing cannot be verified (无法核实).
