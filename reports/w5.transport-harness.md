# W5 public transport harness and review

Completed 2026-10-04. Owned additions are the transport fuzz target, deterministic seed generator and its documentation. Shared Cargo registration and all production changes belong to root/W5.5; frozen B sources were not changed by this transport task.

The target exercises real public registry RAW/BDF/SSFN writers and gzip reading with matching profiles, bounded input/inflation/total resources, original small models, independently variable native/common limits, complete native-versus-gzip model equality and strict diagnostic preservation. RAW writer-only configurations have positive success assertions, so silently allowing every failed gzip write cannot conceal selection of the wrong default reader. BDF has no typed registry setter and is exercised through its actual common-limit adapter; RAW and SSFN exercise both typed and common limits. See `docs/transport-fuzz.md` for control-byte and comparison scope.

Validation passed:

- `rustfmt --check --edition 2024` and standalone fuzz-bin Clippy `-D warnings`.
- 302 original seeds regenerated and byte-checked; first ASAN replay completed 303 executions in one second.
- Short ASAN mutation run: **22,756 executions / 13 seconds**, exit 0, coverage 6214, features 24374, peak reported RSS 444 MiB (including ASAN quarantine).
- Final sanitizer build and corpus replay passed against a stable before/after snapshot of the updated transport production files, including root's decoded-capacity fix.
- Twelve externally produced native/gzip/multi-member input cases were checked through public readers for every original pixel and code. Their fontpixel outputs were independently decompressed by Python `gzip`, and all bytes matched the separately serialized native output. The public reader also confirmed complete native/gzip model equality.

`w5.transport-harness-final-runs.json` records exact final commands, exits, output hashes and unchanged production snapshot. `w5.transport-initial-replay.json` and `w5.transport-smoke.json` preserve short sanitizer evidence. `w5.transport-external-check.json` embeds the complete original temporary Rust probe and Cargo manifest, all 13 commands, 12 artifact hash pairs, Python version and gzip module fingerprint. Its executable/source/output files stay under `../local-work/transport-native-check`. `w5.transport-seeds.json` fingerprints every original seed and the zlib runtime. Python produces input envelopes; fontpixel outputs are verified with Python's independent gzip implementation. No third-party font artwork or implementation source is copied.

Review confirmed that compression occurs after merged strict-report rejection and only for gzip names; native output does not enter the second native audit. Registered built-ins retain their typed writer profile instead of using independently configured registry readers. Common limits only restrict native budgets. The bounded output sink reserves capacity before growth and counts retained raw/wire/report storage.

One additional input-side issue was reported to root: the older inflater grew a `Vec` geometrically but charged only its length, allowing capacity to exceed a tight aggregate allowance. Root fixed capped growth and capacity accounting, including owned sidecars, and owns the corresponding production regressions and freeze. This worker did not modify those files. The final build/replay records the updated snapshot.

The earlier W5.5 mock-writer unit tests already cover call counts and exact envelope threshold semantics; this independent target concentrates on real codecs, varied profiles, mutation inputs and full cross-transport equality.
