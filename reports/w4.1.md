Production implementation is ready for the parent agent's unified Phase 4
validation. This report does not claim whole-stage acceptance or a completed
fuzz/performance gate.

The eleven production files, including the original assembly source and embedded
stub bytes, are individually hashed in
[`w4.1-sourcehash.json`](w4.1-sourcehash.json). Their aggregate SHA-256 is
`f59986aeb80ff38ef81ecb1a79b032f3f814b7118683c3a3c2365a011055eb82`.
The base commit is `cbbaa359c7bad120a3da6dc11c189b46cb4601f7`.
No branch, index, commit, or worktree operation was performed by this worker.

## Delivered behavior

- `draw`: bounded hexdraw grammar, variable rectangular glyphs, ordered comments,
  explicit Unicode scalar labels, grayscale threshold option, native read/write.
- `raw`: explicit geometry/count/first code/bit order/row order/row padding/offset/
  charset; no content detector; named VGA, C64, C64 PRG, Spectrum, CH8 and MSX
  presets. `.64c` imports preserve their prefix and infer exact whole-cell counts.
  New `.64c` output defaults to the common little-endian `$3800` load address,
  editable through `RawLayout.default_load_address`; an existing matching
  `raw.prefix` takes precedence.
- `cpi`: FONT, FONT.NT, DRFONT and standalone CP read/write; multi-page and
  multi-size collections; explicit linear versus segmented pointer handling;
  shared DRFONT indexes and size-major bitmap tables. Native CPX decompression
  validates header and Adler checksums, bounds NRV2B matches, reverses filter 6,
  and parses the resulting CPI without invoking processes or running x86 code.
  CPX writing uses an original MIT 8086 loader and bounded native NRV2B encoder;
  no runtime or build dependency on NASM, UPX or an emulator is added.
- Writers validate their output with the same read limits, compare the full
  model, and report individual mapping, metric, property and source losses.
  Non-resource failures retain omission diagnostics. Source data, temporary
  buffers, output capacity, read-back models, escaped-name formatting and report
  growth share a conservative budget. Resource exhaustion returns a typed error
  without allocating an unbounded secondary report. Reader diagnostic asset-name
  copies are charged before construction.
- Fuzz targets test parsing, successful-output readability under the same limits,
  and full model equality for no-loss results. Independent generated seeds include
  FONT/FONT.NT/CP/DRFONT and CPX literals plus repeated matches. The CPX harness
  also repairs transport checksums on a bounded mutation copy to reach decoder
  branches behind checksum validation.

## Limits and remaining parent validation

The native CPX reader accepts UPX COM method 4 (NRV2B LE16), header versions 10+,
and filters 0/6. The writer emits method 4, version 11, filter zero with a bounded
256-byte match window. Inputs that exceed MODE's 58,880-byte input/decoded limits,
cannot compress to the UPX size condition, or need excessive in-place overlap
return complete bounded conversion failures. Other import compression methods
and filters return explicit errors. Screen fonts are supported; printer
pages fail the entire read. CP exports one page/device, and DRFONT export requires
matching cell geometries and 256 cells per strike. Resource budgets are
conservative and may reject otherwise small final output when live source,
scratch and diagnostics exceed the configured total.

monobit 0.54's multi-page DRFONT writer omits 28 bytes in the next-entry pointer
and writes page-major rather than size-major bitmap tables. Its original invalid
output is retained and rejected, hash
`910d384d2713a16bb66c9a6957053396a86bd7135682965af21a91dfcbb66fe5`.
The native multi-page/multi-size writer passes the independent monobit reader;
bidirectional monobit DRFONT checks use one page/size. Native input also has an
independent reverse-index fixture. No oracle bytes were silently repaired.

The parent owns CLI/registry integration and the final workspace, fuzz-duration
and performance gates. Seed directories are `../local-work/w41/seeds/{draw,raw,cpi}`.
`w41_timing` provides inspect, conversion and in-memory timing modes for review.
The final CPI fuzz run must include the added `Version::Cpx` writer and the
`font-compressible` / `native-cpx` seeds; the earlier reader-only freeze is
superseded. Draw, raw and console production bytes were not changed.
