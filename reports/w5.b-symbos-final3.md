# W5.B final3: fuzz the complete SymbOS detector

Final3 retains the production/test/document fix from final2 and additionally calls `SymbosCodec::detect` inside the existing bounded SymbOS fuzz target before its independent read/write checks. Every mutated input now reaches the structural probe without depending on parser success. The detector's `Result` is intentionally ignored; the reader still independently decides whether input can be decoded.

This change was requested by the coordinator so the new >=610-second ASAN acceptance run includes detector mutations. No new short fuzz run or repeated production gates are required: final2 already records five ASAN tests of the changed detector and all feature gates. Final3 records rustfmt 2024 and successful sanitizer-enabled fuzz target compilation in `w5.b-symbos-final3-build.json`. The coordinator owns the formal long run.

The original and final2 manifests remain available. Only the SymbOS production source, test, document and fuzz target differ from the original B freeze; the other 40 owned paths remain byte-identical.
