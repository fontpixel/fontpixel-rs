## Scope and findings

Reviewed PLAN §§4.5, 5.3 and 9.4, the format and decision records, actual native
planning/export/GSUB/subset/CLI code, independent-tool drivers and raw evidence.
The implementation covers the required Tong-style single `locl` behavior,
language/script alternatives, bitmap-and-metric deduplication, text/codepoint
selection, dependency closure, and sfnt/WOFF/WOFF2 output. General contextual or
ligature layout is not an unstated requirement of this work item.

Four confirmed defects were corrected on the separate review branch:

1. **Inherited metrics:** glyph identity and export used raw optional fields,
   then borrowed the base Font's defaults for other source faces. Each face's
   own defaults are now resolved before deduplication. Equal explicit and
   inherited metrics share a glyph; different effective metrics remain distinct.
2. **Embedded vertical metrics:** outline vhea/vmtx could coexist with
   horizontal-only bitmap records. Vertical-bearing/advance information now
   survives in big sbit metrics, including through subsequent subsets.
3. **Unsafe table drops:** dropping only vhea left vmtx behind and OTS rejected
   the result. The optional pair must now be explicitly dropped together, with
   normal loss diagnostics. Failure leaves an existing destination intact.
4. **Macao language mapping:** `zh-MO` previously selected Hong Kong's ZHH.
   It now selects the registry's ZHTM, while explicit Hans still selects ZHS.
   HarfBuzz independently verifies Macao versus Hong Kong routing.

The first two new unit reproductions failed on the original candidate; their
unmodified failure logs are retained. The unpaired-drop OTS failure is retained
separately. Four new unit tests bring the variants test file to 21 tests.

## Performance and remaining boundaries

The refreshed five-run measurements and validated output sizes are in
`benches/results/variants-review.json` and `benches/VARIANTS-REVIEW.md`. The original
candidate measurements remain separately available. These runs parse all five
Large regional/script sources, including the TC/HK alias. They do not establish
the whole phase's 84-file export or ≤40-second target.

- CFF subsets conservatively retain unused strings, subroutines and Font DICTs.
  This preserves SIDs, subroutine bias/computed-call semantics, hints and private
  data, but the small text subsets remain roughly 484–486 KB versus 6–10 KB TTF.
- Unsupported GSUB behavior, filtering flags, GPOS/GDEF, variable/color or unknown
  glyph-indexed tables fail rather than retain stale glyph IDs. Exact requested
  table drops report loss; strict output refuses it.
- UVS/non-Unicode cmap records and explicit nondefault legacy CFF Encoding remain
  explicit unsupported cases. CFF2 and previously documented unsupported outline
  forms remain outside this item's single-locl/Tong scope.
- Subsetting preserves outline flavor; it is not TTF↔CFF conversion.
- Diagonal advances and non-centered explicit vertical origins are rejected.
  Synthesized bitmap origins use an integer cell midpoint; explicit representable
  bitmap origins are retained exactly.
- The supplied package lacks complete Small/monospaced regional source sets.
  All supplied Large regional and all supplied Latin sources were checked;
  missing coverage and whole-phase performance are not claimed.
