# W4.3 NFNT handoff

Status: native implementation and local checks complete; root-owned 610-second fuzz, five-run performance measurements and full shared integration gate are pending. This is not a claim that Phase 4 is complete.

Implemented native Rust NFNT/FONT raster reading/writing, FOND associations and opaque optional tables, multiple strikes, resource forks/dfont/suitcase, MacBinary I/II/III, AppleSingle/Double v1/v2, and ReadContext/OutputBundle pairing. New MacBinary/Apple envelopes use II/v2; original supported envelope versions and metadata survive same-container writes. Classic FONT size-zero naming resources and family/size IDs are supported. Mono and 2/4/8-bit grayscale, indexed fctb palettes, explicit grayscale reduction, checked resource ranges, cumulative budgets and field-specific loss reports are covered. The API is in `crates/fontpixel/src/formats/nfnt.rs`; field definitions and source decisions are in `docs/formats/nfnt.md`.

Twenty-four authored sources exercise native/monobit readers, monobit writers, native raw/dfont/FONT writers; additional cases cover classic naming resources, multiple strikes, all supported envelope versions, palettes and three independently generated legal real files.
- Original fuzz corpus generated by `fuzz/seed_nfnt.py` at `../local-work/w43-nfnt/seeds`; no downloaded binary is included in the repository. The fuzz harness checks same-limit writer readability for raw, dfont, MacBinary, AppleSingle and paired AppleDouble; any no-loss output must preserve the entire FontSet.

Commands used `CARGO_TARGET_DIR=../local-work/target-w43 CARGO_BUILD_JOBS=2 CARGO_PROFILE_DEV_DEBUG=0 CARGO_INCREMENTAL=0`. The oracle is `../local-work/oracles/bin/python`, monobit 0.54. The benchmark driver is `nfnt_timing time <path> <iterations>`; it measures native read/write loops independently and prints JSON. No long fuzz or performance gate was run by this worker.

Monobit 0.54's NFNT raster reader treats the fctb flag as Lisa compression. The color oracle therefore separately decodes its ColorTable using monobit's low-level parser and checks coverage with Pillow's BT.601 conversion. This limitation is recorded rather than treating an oracle failure as an implementation failure. Native tests cover explicit and positional palettes, partially unspecified palettes, malformed indices and changed pixels with retained original palette metadata.

Known explicit limits: Lisa-compressed and synthesized resources are rejected; bare color data needs its palette-bearing resource context. Glyph mappings are legacy bytes and require explicit charset conversion for Unicode. FOND optional width/kerning/style tables are preserved as opaque bytes, not exposed as native kerning-edit APIs. Indexed RGB becomes Gray8 with a loss report while source RGB bytes remain retained; unspecified port colors use an explicitly reported white-to-black convention. Geometry outside NFNT field ranges is rejected. Shared payloads/partial overlapping ranges are rejected; exact shared Pascal names are allowed. Old FONT authoring uses sizes 1–127 and family IDs 128–255. Original raw resources survive unchanged raster writes; regenerated edited resources report metadata differences.

The earlier `w4.3-prepalette-freeze.json` is a historical source snapshot, not the final validation manifest. Use `w4.3-freeze.json` for the final files to run under root's fuzz/performance gate.
