## Decisions and boundaries

See the four W0.2 entries in `docs/decisions.md` and `docs/charsets.md`.

- `iso2022cn` is SPEC's GB2312 GL **glyph-code** designation. This does not
  implement stateful ISO-2022-JP/KR/CN byte streams. HZ remains excluded by SPEC
- Numeric APIs preserve Python's surrogate identity behavior; Rust `char`
  conveniences reject surrogates
- Unknown names expose `known() == false` and identity. Integrating the SPEC's
  once-per-name warnings into the actual font/compatibility Report remains W1.5
- DEFAULT/OEM/MAC/SYMBOL FNT values require source-context or explicit mappings;
  they are not silently guessed. Actual format codecs, bespoke machine presets,
  and CLI charset conversion remain assigned to their later work items
- Python codec parity does not claim every later revision of GB18030 or other
  standards. A changed runtime map must trigger reviewed regeneration
- No fonts, reference files, samples, or font-fixing directories were changed.
  No phase-1 work, automatic main merge, push or phase bundle was performed
