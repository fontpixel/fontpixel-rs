# W5.C2 workstation and printer codecs

Seven independent native readers and writers are implemented: Catalyst, ChiWriter, Dashen, HP PCL, Adobe Prebuilt, RISC OS and Xerox AL/BITBLT/PrePress. All expose typed options and codec traits, use cumulative allocation/glyph limits, and verify successfully written output by reading it under the same limits. No new runtime dependency is required. `dashen` enables the native `hppcl` dependency for embedded printer strikes.

The public specifications and empirical limits were documented before implementation. Source and license evidence is in [w5.c2-sources.json](w5.c2-sources.json); no GPL/MPL/EPL implementation was copied. The Adobe interface and original producer are used only as external layout evidence. Original fixtures and independent decoders are project MIT source.

## Exact scope and limitations

| Family | Native read/write scope | Explicit limits |
|---|---|---|
| Catalyst | Multiple128-slot resources, two offset origins, Apple seven-bit raster/color-byte retention | No authoritative publisher spec established; offset origin typed; no automatic registry detector |
| ChiWriter | V3/V4, contiguous and explicit absolute/relative compatible directories, optional stride | Directory/width overlap rejected; hidden ink retained with Loss; filename Latin-1≤13 bytes |
| Dashen | V3 screen, V4 screen+PCL collection, authoritative offsets and optional code map | Unverified V1 rejected; duplicate mapped present codes rejected |
| HP PCL | Bitmap font headers, LaserJet character format4, raw/RLE, continuations, all orientations | Other printer/scalable character descriptors rejected; historical size16 descriptor field requires explicit read compatibility |
| Prebuilt | Version3, both byte orders, multiple matrices,1/2/4/8-bit masks and vertical arrays | Affine/fractional projection and provisional vertical semantics report Loss; reduction/threshold explicit |
| RISC OS | XY raw Gray4; FONT4–8 raw Mono/Gray4 and packed Mono; signed12-bit;1/4/16 phases; scoped IntMetrics0/1/2 input,0/2 output | Outline/dependent vector glyphs rejected; output phase grid must be complete; extra kern/misc data retained with Loss; V2 metric output codes≤65534 |
| Xerox | AL extension chains; plain/kerned and indexed BITBLT; AC collections with two advance axes and exact fixed-point source fields | AL bitmap rows pad to16 columns with audit; rotation metadata retained with Loss; kerned255/255 is reserved for absence |

Independent-oracle differences are not hidden. Monobit Catalyst divides by zero for zero-width slots, so dense128-slot fixtures establish interoperability. Monobit does not follow explicit Catalyst/ChiWriter offsets or implement new RISC OS phase/version profiles; native original fixtures exercise those paths separately. The original NeXT producer was compiled and run externally: five BDF→LEPF outputs establish MSB-first pixels independently of integer byte order. Native reading and writing preserve their Mono and grayscale pixels and advances. Monobit LEPF comparisons use a numeric-only BE view with raster bytes unchanged. Its Alto y origin is one row above the primary specification, AC retains storage padding and ignores vertical advances, PCL font baseline uses the wrong unit, and Prebuilt vertical interpretation is unimplemented. Comparisons state each normalization, and primary-derived tests assert native values independently.

Extensions: Catalyst uses `SYSTEM.FONTS`; ChiWriter `.set`; Dashen `.pft`; HP PCL `.sfp`/`.sfl`; Prebuilt `.bepf`/`.lepf`; RISC OS uses names such as `x90y45` and `IntMetrics`; Xerox `.al`/`.strike`/`.ks`/`.ac`. Strong filename inference is not substituted for reliable structural detection.

## Final detector correction

The first freeze was superseded after independent registry review found three false candidates: RISC OS claimed a valid FONTX2 file by its four-byte prefix, ChiWriter claimed QPF by its type byte, and Xerox BITBLT claimed a Palm/NFNT file despite trailing bytes outside its declared bodies. Final detection now checks native header fields and complete usable raster/table extents without allocating model objects or pixel buffers. Dedicated regressions retain valid native profiles; all seven fuzz targets now call `detect` as well as read/write. The legitimate Palm/NFNT ambiguity is preserved. `w5.c2-freeze-superseded1.json` preserves the original manifest verbatim. New gate and smoke commands are in `w5.c2-detector-gates.json`; unchanged pixel/metrics oracle artifacts remain valid.

Fresh native-library probing of the exact reviewed FONTX2, QPF256, QPF2048 and Palm/NFNT artifacts confirms all four invalid C2 candidates now return NoMatch; command output and fixture hashes are in `w5.c2-detector-real-fixtures.json`. All three changed features passed independent test/Clippy/rustdoc again, and all seven updated detector/read/write fuzz targets completed6-second ASAN checks with exit0.
