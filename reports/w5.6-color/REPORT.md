## Delivered behavior

- Public `embedded::{ColorFlavor, ColorWriteOptions, write_color}`. `Cbdt` is the
  default; `Sbix` is explicit. Existing `EmbeddedWriteOptions` stays unchanged.
  `EmbeddedCodec.color_write_options` supports the coordinator's registry/CLI
  wiring. `embedded::write(..., Kind::Color, ...)` also writes default CBDT.
- Low-level `bitmap::encode(..., Kind::Color, ...)` emits CBLC/CBDT v3 with depth
  32, index 1, PNG image 17/18, raw image 1/6 for zero-area rectangles. Pixel and
  horizontal/vertical embedded metrics are exact. Existing OTB/bdat encoders
  retain their encoding conventions and regression tests.
- `bitmap::color::encode_sbix` emits sorted ppem/PPI records with sparse glyph
  indexes. Native sbix supports uint16 ppem, int16 origins and bitmap dimensions
  beyond the uint8 CBDT bounds. No fake outlines are created. The 512-ppem,
  300×256-pixel fixture renders correctly with system FreeType.
- Mono and Gray8 encode as deterministic black RGBA PNG with original alpha
  coverage. PNG uses original, specification-derived stored DEFLATE code and
  exact-size buffers. Both native read projections return the same coverage.
  Mono-to-Gray8 representation changes, omitted empty sbix images, incompatible
  shared advances/line metrics, vertical sbix metrics and source metadata losses
  are reported. Registry strict mode rejects those losses; plain Gray8 can pass.
- Bounds cover glyphs, tables, complete output, PNG scratch, cumulative PNG
  decompression, pixel work and a conservative model/readback allocation envelope.
  Every successful native color write is read back with the identical limits.
  Low-level output also validates against its respective reader. No subprocess
  or external font engine is used in production. Index/mapping work uses ordered
  maps and direct index arrays, without all-pairs glyph scans.

The private common-table helper was generalized to wide design metrics for sbix.
The OTB/bdat reference-pixel scale (100, or 64 above 163 ppem) remains unchanged.
New sbix global metrics use a legal upem up to 16384 and explicit rounding losses.

## Decision text for coordinator-owned decisions.md

2026-10-04: W5.6 color output uses explicit CBDT/CBLC or sbix with black PNG alpha
coverage, retaining Gray8 samples without inventing an RGB model. Mono expansion
is reported. CBDT uses raw zero-area records because PNG forbids empty dimensions;
sbix omits those records and reports lost explicit strike membership. sbix uses
shared hmtx metrics and diagnoses incompatible per-strike advances/line metrics.
Native writes must reread with identical limits, including bounded PNG scratch
and cumulative decoded data. Original stored-DEFLATE PNG output provides exact
buffer accounting and deterministic linear work; no external encoder is invoked.
