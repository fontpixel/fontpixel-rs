## Decisions and known limits

- YAFF is the lossless native golden format via documented namespaced extensions.
  Portable consumers read its pixels/labels/horizontal metrics but can discard
  extension-only state on rewrite. Canonical output is deterministic, not a
  promise of original YAFF whitespace/comment positioning/quote spelling.
- Unsupported vertical/kerning/scalable fields are retained as source properties;
  this phase does not interpret or render them. `multi-cell` uses native
  CharacterCell classification with the original text retained. Path-only glyphs
  are rejected explicitly; stroke rasterization is not claimed.
- Gray4/Gray16 sample values map exactly to Gray8 coverage. Output uses 256 levels
  whenever any glyph is Gray8, while metadata preserves native mono/gray identity.
- Sized zero-area rasters preserve dimensions. Stock monobit normalizes them to
  0×0 when writing; the native exact-roundtrip contract is independently tested.
- Bounded integer arithmetic can reject metrics whose derived YAFF bearings
  overflow i64; invalid UTF-8, forbidden raw controls/noncharacters and malformed
  structures are errors, not silent repairs. Extension source strings escape
  those otherwise unprintable values and retain their exact contents.
- A canonical regression golden is generated by Rust; semantic correctness is
  separately crosschecked with monobit. No independent byte-identical YAFF oracle
  is claimed because the format permits multiple equivalent representations.
