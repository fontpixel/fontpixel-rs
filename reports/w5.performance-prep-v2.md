## Coverage and contracts

The expanded inventory has 185 cases: the original 90, B's 28 emitted profiles plus a distinct VFNT rebuild case, C2's 41 original seed profiles, E2's 24 image/outline cases, and one shared raw/gzip transport case. There are no pending format groups. The generated `benches/phase5-cases.json` and `phase5-README.md` give exact interfaces and operation scope.

The native adapters remain owned by their format workers and were not modified here. Their actual counts and unit contracts are retained: B has 100 reads and 20 writes; C2 has 300 of each; E2 image writers execute one operation, while their readers use the requested count. The original image writer model, including metadata and Gray8 pixels, remains separate from emitted native reader fixtures. Native default behavior remains the baseline. VFNT's default byte replay and its explicit rebuild are separate rows. No full-model serialization or I/O is added inside native timing loops.

B covers BeOS, Oberon, SymbOS, wsfont, VFNT, GEOS, GPI and PC/GEOS variants. C2 includes Catalyst, ChiWriter, Dashen, HP PCL, Prebuilt, RISC OS and Xerox Alto/BITBLT/Prepress. E2 includes PILfont, SFont/RFont, VLW 8–11, imageset directories, SSFN binary/text/gray/repeat/collection/gzip and both PFR dialects with raw/RLE/multiple strikes. The transport probe splits raw and gzip read/write observations and includes the second native write-budget audit in gzip's cost.

## Independent consumers and limits

Python uses the unchanged monobit 0.54.0 installation. New B/C2 profiles receive a baseline only where their original fixtures have independent validation. RISC OS calls the original loader directly with a memory-only optional IntMetrics resolver: monobit's registry replaces the supplied location and cannot preserve that resolver. No installed oracle source is patched. Prebuilt little-endian data has no direct monobit timing baseline because upstream mirrors its MSB-first rasters; the original NeXT producer proves the native behavior. Alto's baseline adjustment, Prepress's storage padding and Prebuilt's missing vertical advance remain documented comparison limits.

PILfont uses Pillow's unchanged in-memory `_load_pilfont_data` decoder, with companion PNG decoding included and advance validation outside the timer. VLW uses Processing's `PFont(InputStream)`; SFont/RFont use BitsNPicas' `importFont(byte[])`. An original small Java API wrapper is generated and compiled outside production, and ImageIO disk caching is disabled before timing. Its source, class, JAR and JVM executable hashes are retained. BitsNPicas adds a virtual space for SFont, so its actual 95 returned glyphs remain distinct from native's 94 encoded glyphs. No model is trimmed to manufacture equivalence. Imageset uses monobit's unchanged directory reader over preloaded assets.

PFR's FreeType dialect uses FreeType 2.13.2 through freetype-py, with direct fixture-known U+0041 lookup across all strikes, full bitmap/metric materialization and original pixel assertions outside timing. Face creation and Python-wrapper overhead remain included and labeled. There is no 65,536-code scan or quadratic repeated buffer conversion. SSFN's author converter, GPI's original tools, native GEOS/PCGEOS consumers and other file/process correctness tools do not become invented memory-timing baselines. Unsupported operations and engines are null. No automatic speedup ratios are produced.

The runner and new thin wrappers are original project MIT code. Monobit is MIT; Pillow is MIT-CMU; freetype-py is BSD, using the externally installed FreeType library. Processing and BitsNPicas are external executable/JAR consumers only, under their upstream terms already documented in `THIRD_PARTY_NOTICES.md`. No GPL/MPL/LGPL decoding implementation was copied into production or the runner. Frozen oracle provenance remains in `reports/w5.b-*`, `reports/w5.c2-*`, `reports/w5.e2-image/` and `reports/w5.e2-outline-provenance.*`.

## Evidence and formal-run guards

The accompanying JSON preserves command/exit metadata, source and executable identities, original fixture hashes, actual iteration/glyph counts, oracle dependency identities, raw-output hashes and exact evidence paths. Nonformal timing values are deliberately omitted from its summarized interface records; complete raw smoke output remains in the external work directory. Peak RSS is whole-child `wait4` RSS, including runtime and setup, not isolated codec allocation. Rows from one process share that process RSS observation.

Normalizer selfchecks cover 16 unit/count/shape/availability invariants. Seven guard checks launch zero measurement processes and exercise explicit smoke-only rejection, missing quiet confirmation, absent machine notes, competing task activity, unchanged/stale owner proofs, and replaced release binaries. Owner manifests and their declared owned sources are checked before preparation and measurement; global Rust/adapter/seed/crosscheck identities, original fixtures, external package sources and binaries are also verified. Source additions or edits invalidate formal evidence. `--skip-build` and `--smoke-only` can never produce an eligible preparation.

Formal measurement still requires a fresh eligible preparation, unchanged sources and binaries, a coordinator-confirmed quiet window and a machine-activity note. The runner checks build/fuzz/consumer and competing runner processes before and after measurement. Failed runs retain raw logs and append-only progress JSONL, with atomic final summary writes and no successful formal result. These checks supplement coordination; they cannot establish system-wide silence themselves.

Exploratory preparation records are retained separately. Early upstream RISC OS location errors and the Xerox `bitblt-dense` naming mismatch were corrected only in the new runner; all nine targeted cases then passed with 18 engine records. The initial all-group build ran alongside continuing format/resource fixes, so its source-drift record is evidence of a busy smoke, not an accepted timing snapshot. Codec sources and worker-owned adapters were never changed to accommodate performance preparation.
