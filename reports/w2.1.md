## 6. 范围、限制与协调者注意

- 这是 sfnt 公共 API 的验收，不是第 2 阶段整体完成。没有新注册任何通用字体
  codec；TTF/OTF/OTB/WOFF/WOFF2/TTC 等尚保持原生未实现状态。
- 字形轮廓/内嵌点阵/CFF/GSUB locl/容器压缩/Tong 全家族等价与性能是后续工作；
  现有测试复用已验收兼容轮廓，不声称实现 W2.2 的通用原生 codec。
- cmap nominal projection 不保留 symbol/Mac 旧编码或 UVS；raw/Fontations
  可另取这些数据。post 历史 2.5/4 使用 raw 保留；规范 writer 拒绝不合规范名字。
- head/maxp 字段和字形 ID/设计单位选择由上层负责；完整字形程序与表间语义不能
  只用 container checksum 验证证明正确。未知表 raw 保留不保证子集/重编号安全。
- OS/2 code-page helper 是保守的完整可打印 repertoire 判断，未复制 fontTools
  的代表字符 heuristic；特殊 OEM/symbol 与未列页面由调用者显式决定。
- 保留历史中断报告供追溯。此工作分支提交交协调者 review/merge；本 worker
  没有改 main、推送、发布、部署或开始下一工作项。
