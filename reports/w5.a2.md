# W5.A2 — native historical font families

Implemented native read/write for BBC, seven COM envelopes, Consoleet directories,
old GRASP, HRCG, Wyse, XBIN and both Zap variants. Root owns shared feature/registry,
CLI and manifest integration. This worker modified only its assigned eight codec
families, documents, tests, fuzz targets, bridge, seed/crosscheck scripts and reports.
No W5.5 frozen C/DRCS files or reference samples were changed.

## Implemented scope

| ID | Native coverage | Representation or explicit limitation |
|---|---|---|
| bbc | Printable VDU 23 records, 8×8 | Legacy 32–255; duplicate definitions report Loss; other controls fail |
| comfont | FONTEDIT, Frapt, Frapt TSR, LETAFONT, Font Mania, PSFCOM, UDG | Original executable stubs; explicit CP/M target; input never executed |
| consoleet | Native PCLT directory, variable cells | Bounded listing/resources; explicit Legacy/Unicode filenames |
| grasp | Original seven-byte fixed-cell header | Byte-width/count constraints; new GRASP is a separate family |
| hrcg | 768-byte AppleSoft SET, phase-preserving rows | 14×8 model, both half-dot phases in one row rejected; explicit selection |
| wyse | WY-60 four banks, 00–7F positions, 8×16 wire rows | Display-repeat columns excluded from file raster |
| xbin | 256/512 fonts, palette, all four screen RLE modes | Preserved native screen properties or explicit FontOnly projection |
| zapfont | ZapFont and ZapRedraw UCS | Actual ordinal tables, aliases/nulls, non-byte widths; invalid Unicode rejected |

All writers audit the decoded output model, including metadata, mappings, metrics,
added blank slots and Gray8 projection. Strict mode rejects Loss. Native COM
runtime projections also report Loss: alternate-line installation of 16-row PSFCOM
on eight-row targets, and Spectrum's narrow second bank. Same-limit successful
write/readback is checked inside the writer and by tests/fuzz harnesses.

Allocation accounting covers source model, maps, temporary rasters, output paths,
output buffers, readback and report entries. Offset/length arithmetic is checked.
Consoleet checks physical encoded text length before raster allocation, even when
caller aggregate/pixel/table limits are usize::MAX. Other native variable-size
raster containers validate input spans before allocating the decoded glyphs.
Code maps use ordered maps; there is no pairwise glyph search in these codecs.

## Validation and reproducible commands

Environment before every Rust command:

```sh
source scripts/local-env.sh
export CARGO_TARGET_DIR="$FONTPIXEL_WORK_ROOT/target-w5a2" CARGO_BUILD_JOBS=2
```

`reports/w5.a2-gates.json` records the exact per-feature test, Clippy and rustdoc
commands, exit codes and external logs. For each of the eight features these are:

```sh
cargo test -p fontpixel --no-default-features --features FEATURE --test FEATURE
cargo clippy -p fontpixel --no-default-features --features FEATURE --lib --test FEATURE -- -D warnings
RUSTDOCFLAGS='-D warnings' cargo doc -p fontpixel --no-default-features --features FEATURE --no-deps
```

The eight feature-specific suites contain **30 tests**, including original wire
fixtures, native ranges/phases, every XBIN compression mode, malformed/truncated
sections, directory aliases, same-limit reopening, strict projections, extreme
baselines and high-limit/small-input allocation guards. Combined Clippy includes
the bridge and all tests. The dedicated fuzz-target Clippy command is recorded in
the final gate metadata. Owned Rust files also pass rustfmt --check.

```sh
cargo build -p fontpixel --release --no-default-features \
  --features bbc,wyse,grasp,hrcg,xbin,consoleet,zapfont,comfont --example w5a2_timing
"$FONTPIXEL_WORK_ROOT/w5a2/oracles/bin/python" tests/crosscheck/w5a2.py
python3 fuzz/seed_w5a2.py
```

The crosscheck records **33 cases** with native raster/metric/code comparisons,
original spec fixtures, and real x86/Z80 instruction execution of the project's
writer outputs. DOS coverage includes 8/32-row fonts and TSR reinstallation;
CP/M covers three targets, 8/16 rows and Spectrum 512 slots. The four fixed-oracle
limitations and original failures are retained, described precisely in
`w5.a2-oracles.md`; they are not silently patched or claimed as upstream passes.
The independent reader matches all ordinary writer payloads. Zap's ordinal alias
case is checked against primary-spec values because the fixed oracle is limited.

Initial ASan smoke ran each target for 21 seconds without failures; after final
allocation/report hardening, a second smoke runs the frozen implementation for
11 seconds per target. `w5.a2-fuzz.json` and `w5.a2-fuzz-final.json` contain exact
commands, executions, sanitizer, exits and log hashes. Root retains ownership of
the assigned >=610-second final runs.

## Performance handoff and limits of evidence

Release adapter:
`$FONTPIXEL_WORK_ROOT/target-w5a2/release/examples/w5a2_timing`.
It loads input before timing and reports native bytes, glyphs, iteration count,
read_ns and write_ns. `time KIND FILE N` measures in-memory operations; directories
are fully preloaded. Fixtures and consumers live in `$FONTPIXEL_WORK_ROOT/w5a2`.
The bridge supports `fixture`, `inspect`, `convert` and `time`; kind names are
listed by the seed and crosscheck scripts. The release build completed, but this
worker does **not** claim formal performance results while the shared workspace
is busy. Root will schedule quiet five-run release measurements and whole-repo
gates. No peak-RSS or speedup claim is inferred from these smoke tests.

CPU emulation validates documented BIOS contracts and memory writes; it does not
claim complete DOS/CP/M emulation or physical terminal/device validation. Primary
sources and oracle versions/hashes are recorded in the individual docs and oracle
report. No additional Rust dependency, vendor loader template or third-party font
sample is included. Requested agent configuration was gpt-6-astra/xhigh; runtime
model identity and fast-mode state are not independently exposed to this worker.

The final owned-file hash manifest is `reports/w5.a2-sha256.txt`.
