# W4.5 implementation handoff — 2026-10-04

PK, GF and Plan 9 are implemented natively behind independent Cargo features.
This handoff records focused verification; the coordinator's final shared checks,
610-second-per-target fuzzing and five-run performance acceptance remain pending.
No production decoder invokes external programs or opens a filesystem path.

## Delivered behavior

- PK: short, extended and long packet headers; all dyn-f values, packed long
  numbers, repeated rows and continuous raw bits; signed fractional metrics and
  the complete unsigned extended-short advance range. Deterministic raw output
  selects the smallest legal header.
- GF: every paint/skip/new-row command, short/long character starts, specials,
  metric locators, bounded raster construction, exact command-boundary pointer
  validation and residue backpointer chains. Glyph-prefixed versus font-postfix
  special ownership survives. Output emits deterministic paint runs and complete
  modulo-256 metrics.
- TeX metrics: exact 2^-20-point design size, 16.16 pixels per TeX point, rounded
  dpi using 72.27 points/inch, exact raw TFM/escapement properties plus integral
  model projections. Glyph reference points and negative bearings are explicit.
- Plan 9: font range manifests (decimal/octal/hex and optional slot offsets),
  cached relative subfont resolution, aliases and multiple sidecars; direct
  subfonts; new/legacy image headers, legacy bit inversion and bounded LZ77.
  k1/k2/k4/k8 coverage is exact; other channel layouts produce explicit conversion
  reports. Both raw output and bounded literal LZ77 output are available.
  Sparse mappings do not scan absent codepoints; line metrics are independent of
  Fontchar's byte coordinates.
- OutputBundle writers preflight source models, removed slots, strings including
  source provenance, property trees, code maps, temporary buffers, reader output
  and diagnostic reservations. Successful output is reread under a budget no
  larger than the caller's; strict/report handling includes each mapping, alias
  identity, slot, metric and ordered/raw property change. Diagnostics are linear
  in alias count, and later fatal errors retain earlier omission reports.

Typed interfaces and CLI registration are integrated by the coordinator.
No new library dependencies were introduced. The only shared file edited by this
worker was the coordinator-authorized Cargo example registration for `w45_timing`.

## Focused verification

27 tests pass: PK 12, GF 6, Plan 9 9. These include independent wire fixtures,
150+ generated raw-bit alignment cases, packed repeats/overflow/truncations,
negative/fractional metrics, full extended advances, GF backpointers and special
ownership, Plan 9 raw/compressed/old images, Gray8 coverage, sparse multisidecar
aliases, line metrics above 255, aggregate limits, unsafe/missing paths,
preflighted provenance/debug-escaped properties, linear alias reports and fatal
omission retention. Lossless native writes assert complete Font equality.

Standalone PK, GF and Plan 9 `cargo clippy -- -D warnings` runs pass. Combined
focused tests/clippy, rustdoc with `RUSTDOCFLAGS=-D warnings`, scoped rustfmt and
compilation of all three fuzz targets pass. The original seed generator covers
all 15 PK dyn-f values, GF commands, Plan 9 raw/compressed/old images and a
multi-resource manifest. Standalone wire seeds were decoded successfully.

`tests/crosscheck/w45.py` records nine independent checks in
`w4.5-crosscheck.json`:

   PKtype/GFtype, then by PKtoGF/GFtoPK reciprocal conversion and native reread.
2. CTAN CMR10 300/329 dpi originals (128 glyphs each) agree with monobit and TeX

## Sources, licenses and disclosed oracle differences

The implementation was written from PKtype/GFtype's descriptive format sections,
the public TUG PK article, and Plan 9 font/image manuals. MIT monobit's PK/GF
readers and Plan 9's permissively licensed readimage behavior were consulted;
no GPL implementation was copied. Production Rust is original MIT code.
The Go BSD module is an external verification dependency only. The crosscheck
script retains no external font binaries in the repository and verifies all
sample downloads by SHA-256. CM originals use Knuth's font license; Plan 9 fixed
font provenance explicitly identifies the original XFree86 sources as public
domain. See the source URLs and hashes in `w4.5-crosscheck.json`.

Monobit 0.54 has no PK/GF writers and no Plan 9 codec, so reciprocal tools are TeX
and Go, not an invented monobit save result. Monobit GF adds a blank right column;
its comparisons use absolute ink coordinates and advances, while native exact
rectangle tests follow GFtype's `max_m-min_m`. Monobit PK does not expose the
preamble's physical metrics; TeX and independent wire tests validate those.
Go's Plan 9 reader only handles compressed modern k1/k2; native broader image
support is covered by original fixtures.

Plan 9 literal compression performs no LZ search and rejects a row too wide for
a 6000-byte block. Raw output remains available; neither mode promises minimal
file size. GF's shared residue metrics cannot express conflicting advances/TFM
widths: omitted mappings receive individual loss entries. Font/subfont widths,
Fontchar fields, and caller resource limits remain explicit representability
constraints. Absolute/runtime Plan 9 font-server paths are not granted filesystem
authority by a relative ResourceResolver.
