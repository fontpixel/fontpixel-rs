## Decisions and integration boundaries

The default phase-1 gate required TTF/SVG dependencies otherwise assigned to
W2.2/W2.8. Exact compatibility implementations were brought forward without
registering native general-format capabilities. W2 still owns broader sfnt/CFF,
embedded strikes, native SVG import, variants and independent validation.

SPEC's dynamic/partial metrics remain native glyph properties; a second font store
was not introduced. PCF output uses raw numeric encodings, ignores temporary
encoding overrides and reconciles derived metadata without deleting source values.
Python's detached-clone removal behavior is distinguished from a stale attached
handle. Lone surrogates use numeric Unicode APIs and a lossless runner transport.

Two pre-existing Rust tests needed representation-only adaptations to optional
serde_json exact-integer feature unification: an explicitly typed empty-byte check,
and the original f64 semantics for BDF version numbers. No expected BDF bytes,
integer precision or differential comparisons were weakened.

## Known limitations and next work

- K12 invalid ragged intermediates are refused transactionally. Valid rectangular
  inputs remain exact. Rust char cannot contain a surrogate; numeric `cp2unicode`
  and `unicode2cp` preserve it, and the differential runner serializes it exactly.
- Rust uses Result/typed options/closures, rather than Python class exceptions,
  JS URLs/canvas, Python file-object polymorphism or binding-language operators.
  Native Debug is a Rust developer representation, not a Python object address.
- Resource bounds deliberately reject oversized inputs/outlines; nested gzip
  transport retains the native explicit refusal. No unbounded recursion/allocation
  compatibility is claimed.
- Full independent fontTools/OTS/FreeType/HarfBuzz coverage and ten-minute fuzzing
  of the new compatibility TrueType reader remain phase-2 robustness work. The
  committed malformed-input tests are not presented as that certification.
- No W1.6 changes, phase-1 completion claim, main merge or release publication.
