# Phase 5 performance preparation

This handoff prepares measurement; **no formal performance result is claimed**.
The coordinator is running concurrent validation and owns the eventual quiet
five-run campaign and `benches/REPORT.md` integration.

New files are the Python orchestrator, its generated case inventory and usage
notes, plus a separate E1 read example. All existing codec implementations,
benchmark/oracle adapters, shared manifests and installed oracle sources were
left unchanged. The W5.5 and W5.A2 frozen manifests were rechecked successfully.
The root added the E1 example's six required Cargo features.

## Prepared coverage

The runner contains 90 cases across A1, A2, C1, E1, X, W5.2, W5.3, W5.4, C/DRCS,
Color and D. The adapters produce 153 engine/format records per interface smoke.
These include all seven original COM wrappers, Consoleet directory resources,
LVGL/U8g2/U8glib/U8x8/NetBSD variants, Hanfont components and 11,172 composed
syllables, Palm/GDR, CBDT/SBIX, QPF/QPF2 at 256 and 2,048 glyphs, and separate
source-replay/canonical D writers including BinHex. B, C2 and E2 are explicit
pending inventories rather than silently omitted entries.

`benches/phase5-README.md` documents exact prepare/smoke/measure commands,
normalization contracts, actual iteration counts, warmups and absent baselines.
The JSON inventory is generated by `inventory`; changes belong in the runner.
Preparation creates original data through the frozen seed/fixture/crosscheck
interfaces, compiles optimized Rust executables, and records complete commands,
exits, binary/fixture/source/oracle hashes and environment details.

The new E1 reader checks original expected pixels at absolute baseline
coordinates, advance and both Unicode/legacy mapping domains, including aliases.
It explicitly checks U8M's additional empty glyph-zero slot. The filesystem
resolver runs only for the initial read; all later reads use preloaded bytes and
side resources. The complete cached model and report equal the initial read.
Five warmups and all correctness checks precede the timed loop. Actual model
glyph counts, pixel counts, primary bytes, resource bytes and report codes are
reported. The nine supported original profiles are RB11, RB12, U8M, Cybiko, HMZK,
SBF, Playdate embedded FNT, split FNT/PNG and compiled PFT.

## Evidence and guards

`w5.performance-prep.json` records final source identities, commands/exits,
interface records stripped of nonformal timing values, checks and retained raw
artifact paths/hashes. The E1 example passes Clippy with warnings denied and
rustfmt. Normalizer selfchecks cover total versus per-operation nanoseconds,
microseconds, seconds, fixed counts, multi-record output, missing writers and
invalid/NaN measurements. Separate guard checks establish that skip-build
manifests, missing coordinator confirmation, missing machine notes and a busy
window are rejected before any measurement process can start.

The saved handoff preparation is intentionally ineligible for formal timing:
other workers changed shared sources during its build. Its subsequent 153-record
smoke had no source changes and passed. The coordinator must prepare again after
source freeze; changing a boolean in the manifest would not establish provenance.

Formal runs require fresh prepared hashes, a release build with unchanged source
identity, five process repetitions, an explicit coordinator quiet-window flag and
an environment note. The runner checks workspace build/fuzz/consumer activity at
both ends; this supplements coordination rather than proving system-wide quiet.
It refuses to overwrite evidence. A failed run retains logs and progress without
publishing a successful formal summary. Source changes in a busy smoke are
recorded and never upgraded into formal results.

## Independent baselines and limits

Python is the unmodified official monobit 0.54.0 release in the shared Python
3.12 environment. Preparation hashes its installed sources/data, interpreter and
records dependency versions. Rust, Python, Java and external native engine
columns are separate. Existing Java/C correctness consumers are not presented as
memory-only timing adapters. Missing engines or operations are null; this
handoff adds no automatic speedup ratios.

COM has no independent writer. XBIN-512 and ZapRedraw writer projections are
explicitly excluded. Palm's frozen adapter reads a bare NFNT input but writes a
PRC container, so only the matching independent reader is listed. Fbit, Lisa,
MGTK and BinHex have no validated matching independent writer in this runner.
The DRCS independent writer drops its reader's malformed `dec_drcs` property
outside the timer, using the exact public-model reconstruction already validated
in W5.5; that projection remains visible in output. PXL receives a memory-only
parent location so absent optional TFM files follow the oracle's documented
missing-resource path. Wyse's extra display columns are cropped before the
independent writer, outside its timer. No upstream sources were patched.

Adapter counts remain authoritative. C1 uses 300 iterations, W5.3 uses 1,000,
W5.4 uses 400, Color uses one operation per process, and other selected adapters
honor the requested count. E1 writer counts describe its source model (Cybiko
and SBF clamp to 190); readers use separate original fixtures and real decoded
glyph counts. Alias counts and font-format default slots are not confused with
source glyph counts. Peak RSS covers the complete child process, not only its
timed loop. Some native writers perform resource/loss audits and a readback that
the independent writer does not perform. These small/fixed workloads do not
replace PLAN section 10 whole-font/catalogue requirements.

Early preparation errors are retained as exploratory evidence: pre-creating X's
output directory conflicted with the frozen generator's creation contract; the
anonymous PXL stream lacked an oracle parent location; an early E1 checker
collapsed duplicate mapping domains; the initial Palm oracle format selected a
PDB loader for a bare NFNT resource. All were confined to new preparation code.
No frozen production codec was changed to accommodate a timing adapter.
