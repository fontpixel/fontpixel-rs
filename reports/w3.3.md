# W3.3 image atlases, C headers and CLI resources

2026-10-04. Implementation, independent review and final validation are complete.
Acceptance is recorded in [the phase 3 report](phase-3.md), including the
integrated fuzz, performance and main-branch gates.
This report supersedes the historical `w3.3/PAUSED.md` checkpoint.

## Implemented scope

Image reading/writing covers PNG, BMP, GIF, TGA and Netpbm, with PNG/BMP/GIF/TGA/
PBM/PGM output. Explicit external maps support regular grids and irregular cells.
Native JSON/TOML metadata preserves complete model fields, stable slot holes,
aliases, sequences, unencoded glyphs, Gray8 samples and default glyph identity.
The atlas contains real pixels. Unknown native fields, overlapping cells,
unmapped visible pixels and unsupported animation fail explicitly.

C reading covers font8x8, t-mat, explicit generic byte arrays and Adafruit GFX.
Generic and GFX output is deterministic and reports unrepresentable mappings,
metadata, depth, cell normalization and glyph-ID changes. The bounded literal
lexer never evaluates C expressions or runs source code. Included headers are
resolved through the same bounded resource interface as image maps.

The CLI resolves resources through a directory capability rooted at the primary
input's parent. Input identities remain open to reject output hard-link/symlink
aliases. Multi-asset output preflights destinations, stages and syncs every file,
keeps recoverable originals and commits the entry point last. Strict-loss failure
returns before filesystem replacement. This is ordinary-I/O rollback, not a
claim of crash-atomic multi-file transactions or isolation from other processes.

Library features remain optional, and no filesystem dependency enters the library.
Contracts and explicit limitations are in `docs/formats/image.md` and `c.md`.

## Independent validation

`tests/crosscheck/image_c.py` verifies the integrated release executable against:

- The supplied MIT catalogue importer and pinned public-domain font8x8 sources:
  **599 glyphs**, with all **7 unmapped rows** reported.
- Independently compiled C11 output (`-pedantic-errors -Wall -Wextra -Werror`)
  and monobit GFX import: **96 glyphs**, exact bits and metrics.
- Pillow decoding of all six image outputs, exact mapped glyph pixels and
  byte-identical canonical BDF readback.
- The full **38,653-glyph Tong SC** BDF, native PNG+metadata and byte-identical
canonical BDF readback under the default aggregate allowance.

`tests/crosscheck/spritesheet.py` independently compares the unchanged catalogue
spritesheet importer with the integrated release. Five fixture groups and 17 CLI
commands cover 9-pixel-wide palette/baseline, blank omission retaining space and
unencoded ornaments, irregular bearings/advances, transparent colored pixels,
visible unmapped rejection and duplicate Unicode rejection. PNG and JSON entry
points agree on every pixel, mapping, name, advance, BBX and font metric. The
explicit 72-dpi BDF convention and strict blank-omission loss are also checked.
Source/binary/artifact hashes are in `w3.3-evidence/spritesheet-results.json`.

Final integrated results are in `w3.3-evidence/crosscheck-integrated-results.json`;
the associated command record supplies the exact source snapshot and exit status.
Original upstream header URLs/revision/hashes and the fetcher are retained under
`tests/data/`. No large third-party font/header artifact is committed.

Dedicated tests cover all six containers with both native sidecars and both
entry points, Mono/Gray8, zero-size/unencoded glyphs, slot holes, metadata/raw bytes,
unknown nested fields, allocation limits, malformed C/geometry, scoped Unicode
comments, explicit array selection, strict loss and missing mappings. CLI tests
exercise sidecar bounds, symlink containment, hard-link protection, target
collisions and destination preservation. The integrated gate and final fuzz
counts are consolidated in the phase report.

## Defects fixed before acceptance

- TGA RLE output crossed scanlines and failed Pillow despite native roundtrip.
  Use uncompressed L8, also avoiding unnecessary four-channel scratch storage.
- Generic JSON allocation estimates overcharged byte properties and duplicated
  glyph metadata, refusing full Tong input. Charge by schema, move metadata into
  slots, release temporary maps before encoding and check encoder/reader peaks
  separately. A 4,000-glyph constrained-budget regression covers this path.
- Same-size C outputs could silently reorder stable glyph IDs. Reordering now
  reports loss, including strict conversion.
- font8x8 ignored explicit array selection; range comments could apply globally
  instead of to their following declaration. Both now follow explicit scope.
- A native generic symbol named `font8x8_*` could select the wrong family.
  Structural declarations and actual native option comments disambiguate it.
- Nested native image metadata silently ignored unknown fields. Shared model
  metadata now rejects them, including YAFF's native extension.
- An entirely unencodable C source lost per-glyph omissions on fatal range
  inference. `ReportedErrors` now retains those entries and a specific fatal code.
  Explicit ranges keep their documented empty-cell generation semantics.

The independent review's reproducers and conclusions are retained in
`w3.3-evidence/`. Final review test cases are also part of the integrated suite.

## Performance evidence and limits

The final five-run measurements use the release `image_c_timing` example on
256 deterministic 9×16 glyphs, with five warmups and 200 reads/writes per run;
1,000 C reads additionally use 1/2/4 threads. Binary hashes, raw records, range,
medians and peak RSS are retained with the phase 3 measurements. Task-owned
builds, fuzz and large oracles must be stopped during those runs; unrelated
desktop/browser activity is documented rather than terminated.

A separate full-Tong process measurement returned 22,445,713 bytes of native
atlas assets at **125,124 KiB peak RSS** and read them back at **150,824 KiB**.
Both processes took about **0.43 s**, but these are single busy-host observations,
not a five-run throughput claim. See `w33-tong-memory-{read,write}.json` and logs.

The library's resource budget is a conservative allocation model, not an exact
RSS ceiling. Large malicious inputs remain bounded by configurable limits. C
syntax outside the documented literal subset and unsupported animation are
rejected. Native atlas metadata is an explicit extension; arbitrary third-party
image files still need a character map.
