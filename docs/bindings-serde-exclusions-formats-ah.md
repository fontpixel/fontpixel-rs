# Serde coverage exceptions: formats a–h and common format types

Scope: public types defined in `crates/fontpixel/src/formats/` files and
directories starting with a–h, plus the common types in `formats/mod.rs` and
the format-facing types in `resources.rs`. Everything else in that scope
derives `Serialize` and `Deserialize` behind the `serde` feature (see the
conventions below). This file lists the types that cannot take both and says
how the Python and WASM/JS bindings expose them instead.

## No serde form (borrowed data, trait objects, handles)

| Type | Reason | Binding exposure |
| --- | --- | --- |
| `formats::Registry<M>` (`fontpixel::Registry`) | Holds boxed `FormatDetector`/`FormatReader`/`FormatWriter` trait objects; private entries. | A native registry handle class. Its methods take typed option dicts/objects (deserialized into the per-format option types) and return serializable results (`FormatStatus`, `Written`, `Report`). |
| `formats::Registration<M>` | Boxed trait objects for one catalogue entry. | Not constructed by bindings; `Registration::status()` is exposed as a `FormatStatus` dict/object. |
| `formats::OwnedWrite<M>` | Internal writer protocol carrying a moved model or a `Result`. | Never surfaced; owned writes return `Written` or raise the mapped error. |
| `resources::Input<'a>` | Borrows the input bytes, filename and a `&dyn ResourceResolver`. | Bindings take `bytes`/`Uint8Array`, an optional name and an explicit resource collection (path → bytes, or a resolver callback) and build the `Input` on the Rust side. |
| `resources::ReadContext<'a>` | Borrowed per-read accounting state handed to codecs. | Not part of the binding API; only custom Rust codecs see it. |
| `resources::NoResources` | Stateless unit resolver. | Implied when no resources are supplied. |

## Serialize only

These are returned descriptors or results. They hold `&'static str` data owned
by the compiled catalogue, so they cannot be deserialized; bindings never need
to accept them as input.

| Type | Reason | Binding exposure |
| --- | --- | --- |
| `formats::FormatInfo` | `&'static str` id, name and extensions. The derive predates phase 7 and its JSON (CLI `formats --json`) is unchanged. | Returned as a dict/object. Callers select a format by its `id` string. |
| `formats::FormatStatus` | Embeds `FormatInfo`. Same CLI JSON, unchanged. | Returned as a dict/object. |
| `formats::Detected` | Embeds `FormatInfo`; a detection result. | Returned as `{format, confidence}`; `Confidence` itself round-trips. |
| `formats::Loaded<M>` | `&'static str` format id; generic over the model. | Returned as a model handle plus `report` and `format`. |

## Validated deserialization

| Type | Serialized form | Validation |
| --- | --- | --- |
| `ResourcePath` | A string. | `ResourcePath::new`: empty, `.`/`..`/empty components, `\`, `:` and control characters are rejected. |
| `OutputBundle` | `{primary, assets, directory}` (`directory` defaults to `false`). | `OutputBundle::new` / `OutputBundle::directory`: duplicates, missing primary, file/ancestor collisions and assets outside a directory entry point are rejected. |

`OutputAsset.bytes` serializes as an array of numbers. Bindings should convert
asset bytes to `bytes`/`Uint8Array` natively rather than through serde.

## Covered elsewhere

- `cybiko::CybikoCodec` and `hmzk::HmzkCodec` are generated by the `codec!`
  macro in `formats/rockbox/common.rs` (unit S3's file, shared with rockbox,
  u8m, sbf and playdate). Their option types are covered here; the macro's
  derive belongs to S3.
- `gf::GfWriteOptions` re-exports `TexWriteOptions` from `formats/pk/common.rs`
  (S3). `gf::GfCodec` derives here and depends on it.
- The shared `bbc/common.rs` (`NativeReadOptions`/`NativeWriteOptions`) and
  `dosstart/common.rs` (`NativeWriteOptions`) option types derive here; their
  i–z aliases (`wyse`, `xbin`, `mkwinfont`, `pcr`, `plus3dos`, `psf2txt`,
  `writeon`) need no further work.
- `gem/common.rs::Budget` and `gdr/wire.rs::{Cursor, Bits, BitWriter}` sit in
  crate-private modules and are not part of the public API.

## Conventions used

- `#[cfg_attr(feature = "serde", derive(serde::Serialize, serde::Deserialize))]`.
- Structs use `deny_unknown_fields`. Structs with a `Default` implementation
  (the documented codec default) also use container `default`, so a partial
  object fills in the remaining fields from it. `WriteOptions` has no `Default`
  and requires `primary_name`; `strict` defaults to `false` as in
  `WriteOptions::new`.
- Enums use `rename_all = "snake_case"` (externally tagged for data variants),
  except `hzk::Preset`, which uses lowercase to match `Preset::name` and its
  `FromStr` (`"hzk16f"`, `"asc12"`).
- `c::ArrayOptions` keeps its existing unconditional derive: the C reader
  parses it from option comments.
- `EmbeddedMetadataOptions.names` (`Option<Arc<NameTable>>`) serializes as
  the table's contents; each deserialized table gets a new `Arc`.
