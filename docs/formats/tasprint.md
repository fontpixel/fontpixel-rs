# TasPrint screen/printer fonts

Primary specification: [John Elliott, TasPrint font formats](https://www.seasip.info/ZX/tasprint.html). The MIT monobit loader/writer is an independent oracle. Spectrum48k/QL contains concatenated 1,920-byte strikes, 96 slots at code32, each 10×16 cell stored as ten top and ten bottom column bytes, bit7 at top. Spectrum +3 uses a checksummed 128-byte +3DOS CODE header followed by little-endian width and 96 fixed sixteen-column cells. CPC uses checksummed AMSDOS headers plus 256 ten-column cells; concatenated CPC files are supported. PCW is sixteen-column cells starting at code1; the primary document says 127 characters while monobit implements 128, so both exact lengths are supported with an explicit count option.

Strong variants are Spectrum48k, Plus3, Cpc and Pcw. Headerless detection based on exact length is only Possible; signatures plus validated headers provide stronger evidence. The read width is explicit for headerless PCW; all stored columns survive in source bytes, and clipped nonzero columns are reported. Codes remain legacy, including CPC's format-specific repertoire. Cells map to x=y=0, advance=declared width and line height16. Wrappers, checksums, metadata and discarded padding are preserved or reported.

Writers support all variants, fix envelope checksums/lengths and return concatenated multi-strike streams where the variant permits it. Numeric Unicode conversion requires an explicit option. Missing slots are blank-filled with Loss diagnostics. Cell alignment must fit without clipping; source/header/model differences are audited against a same-limit reread. Grayscale reduction is explicit and all retained models and assets share one budget.
