# The Print Shop PNF

The primary public reverse-engineering reference is [Rob Hagemans' MIT monobit Print Shop reader](https://github.com/robhagemans/monobit/blob/040b1738085ce7967478499eef2835d2cffc95fd/monobit/storage/fontformats/printshop.py). No vendor specification or verified free native sample is available. Original fixtures and the independent loader validate the documented contiguous-raster profile; unknown offset semantics and application kerning remain explicit limits.

Bytes 0–3 hold maximum dimensions and an opaque word. Widths and heights are 95-byte arrays at 4/99 for codes 32–126. Two 95-word little-endian arrays follow at 194/384. The 27-byte bitmap header at 574 includes a nine-byte name, logo byte-width/height at 590/591, alignment height at 592, and four-byte short name at 593. A packed MSB-first logo begins at 601, followed by contiguous glyph rasters in code order. Glyph y is alignment-height minus glyph height, x=0 and advance=width. The original header, arrays, logo and all file bytes are retained. The undeclared kerning/offset semantics are not invented.

Writing emits the contiguous-raster profile, preserves the original opaque header/logo where present, recomputes dimension and sequential offset fields, and reports changes to unknown source arrays and all unsupported model fields. A weak structural detector never claims a magic signature. Bounds, table lengths, logo allocation, glyph counts, per-glyph pixels and aggregate memory are checked before allocations. Successful output is decoded and audited under the same limits. This is a native reader and writer; application-level Print Shop layout beyond the documented bitmap profile is not claimed.

When glyph dimensions are unchanged, output preserves the original offset table verbatim. When dimensions change or no original table exists, the native contiguous profile writes offsets relative to its glyph-data section and emits `printshop.write.offset_convention` Loss. This is independently readable with monobit; interoperability with the original proprietary Printshop program is not established, and unknown kerning/offset semantics are not claimed as implemented.
