These MIT project fixtures contain original five-row artwork and were assembled
from DAVIC 1.4.1 Annex A by `fuzz/seed_w5e2_outline.py`, without production codec
calls or upstream font data. Names distinguish the published DAVIC convention
from FreeType's deployed offset/position convention. `pfr-ft-multistrike.pfr`
contains two native bitmap strikes in one physical record. Fractional coordinates
are retained with explicit projection loss. Every byte is reproducible; hashes
are included in the W5.E2-outline freeze report.
